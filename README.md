# 🫀 Heart Disease Analysis | Microsoft Excel

### Transforming Healthcare Data into Meaningful Insights

## 📌 Project Overview

Healthcare data can reveal valuable patterns about patient characteristics and disease distribution when properly cleaned, analysed and visualised.

In this project, I used **Microsoft Excel** to analyse a healthcare dataset and develop an interactive dashboard exploring heart disease distribution and selected patient characteristics.

The project demonstrates my ability to prepare raw data, handle inconsistencies, perform exploratory data analysis, build interactive visualisations and communicate findings through a dashboard.

## 🎯 Project Objectives

* Examine the distribution of heart disease among patients.
* Explore demographic patterns across age groups and gender.
* Investigate the relationship between heart disease status and selected patient characteristics.
* Analyse health indicators, including chest pain type, resting blood pressure and cholesterol levels.
* Build an interactive dashboard to communicate findings effectively.

## 📂 Dataset Description

The original dataset contained 1,020 patient records. Following data preparation, the cleaned dataset used for analysis contained **1,005 patient records**.

Key variables included:

* Patient ID
* Age and Gender
* Chest Pain Type
* Resting Blood Pressure
* Cholesterol Level
* Maximum Heart Rate
* ST Depression
* Exercise-Induced Angina
* Heart Disease Status

## 🧹 Data Cleaning and Preparation

Before analysis, I reviewed the dataset to identify inconsistencies and improve data quality.

Key preparation activities included:

* Identifying and handling missing values.
* Standardising inconsistent gender entries.
* Cleaning heart disease status values.
* Categorising patients into age groups.
* Creating resting blood pressure and cholesterol categories.
* Organising the cleaned data for analysis.

Missing or unavailable information was retained as a separate category where appropriate to avoid treating unknown values as confirmed results.

## 📊 Key Findings and Insights

The analysis of the 1,005 cleaned patient records revealed the following:

**1. Heart Disease Distribution**

* 398 patients (39.6%) were classified as having heart disease.
* 375 patients (37.3%) were classified as not having heart disease.
* 232 patients (23.1%) had unavailable heart disease status.

**2. Age Distribution**

Among patients classified as having heart disease, the 70+ age group recorded the highest representation, accounting for approximately 33.2% of the group.

The average age of patients in this filtered analysis was approximately 60 years.

**3. Chest Pain Type**

Asymptomatic chest pain had the highest recorded count among patients classified as having heart disease, with 93 patients.

**4. Resting Blood Pressure**

Among the 398 patients classified as having heart disease:

* 194 had normal resting blood pressure.
* 99 were categorised as having high resting blood pressure.
* 91 had elevated resting blood pressure.
* 9 had low resting blood pressure.
* 5 had missing readings.

These findings describe patterns in the dataset and should not be interpreted as evidence of causation or as clinical diagnoses.

## 📈 Dashboard Development

I developed an interactive Excel dashboard featuring:

* Key performance indicators (KPIs).
* Visualisations of patient demographics and health characteristics.
* Age-group analysis.
* Resting blood pressure analysis.
* Chest pain type analysis.
* Interactive slicers for exploring selected patient categories.

The dashboard provides a focused view of the data, with several visualisations filtered specifically to patients classified as having heart disease.

## 💡 Challenges and Lessons Learned

This project strengthened my practical understanding of data preparation and exploratory analysis.

One important lesson was the need to distinguish between missing information and confirmed negative results. I also learned how Pivot Tables and Slicers can simplify complex datasets and make dashboards more interactive.

Beyond the technical skills, this project improved my ability to interpret data, identify patterns and present findings in a way that supports better understanding.

## 🚀 Conclusion

This project represents a practical application of Excel in healthcare data analytics. It strengthened my interest in exploring how data can support healthcare insights and informed decision-making.

I look forward to applying these skills to more complex analytical projects using tools such as Power BI, SQL and Python.
